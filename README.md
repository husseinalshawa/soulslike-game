# Soulslike Game — لعبة سولز عالم مفتوح (قيد التطوير)

لعبة سولز مستوحاة من Elden Ring تُبنى على مراحل. **المراحل المنجزة: 1 — جوهر
القتال، 2 — حلقة السولز، 3 — العالم المفتوح «المرج الذابل»**: منطقة 400×400م
بتضاريس إجرائية حتمية وغروب ذهبي شاحب، الحصن المهجور (الساحة والبوس) على هضبة،
كهف بكنز أرواح، معسكرا أعداء بنيران مخيم، 3 مواقع راحة، وحصان استدعاء للتنقل.
خارطة الطريق والمواصفات في `docs/superpowers/specs/`.

## التشغيل على جهازك (أول مرة)

1. ثبّت **Unity 6 LTS** (عبر Unity Hub).
2. افتح هذا المجلد كمشروع Unity (أول فتح يبني مجلد Library — يأخذ دقائق).
3. من القائمة العلوية نفّذ بالترتيب:
   - **Tools ▸ SoulsGame ▸ 0 - Setup URP** (ينشئ ويفعّل خط أنابيب الرسم URP).
   - **Tools ▸ SoulsGame ▸ 1 - Create Data Assets** (ينشئ ملفات الموازنة).
   - **Tools ▸ SoulsGame ▸ 2 - Create Arena Scene** (ينشئ مشهد الساحة ويحفظه).
4. اضغط **Play** — الساحة واللاعب والعدو والواجهة تُبنى تلقائياً عند التشغيل.

> إن سألك المحرر عن تفعيل Input System backends وأعاد التشغيل فهذا طبيعي
> (المشروع مضبوط على نظام الإدخال الجديد). وإن ظهرت المواد وردية تأكد من
> تنفيذ خطوة Setup URP.

> ملاحظة: المشروع أُنشئ في بيئة سحابية بلا محرر Unity، لذلك كل المشاهد
> والكائنات تُبنى برمجياً (`GameBootstrap`) بدل ملفات مشاهد يدوية، وكل منطق
> اللعبة مغطى باختبارات تعمل محلياً عبر `scripts/run-tests.sh` (dotnet + NUnit)
> وتعمل نفسها داخل Unity Test Runner (نافذة Window ▸ General ▸ Test Runner).

## التحكم

| الفعل | كيبورد/ماوس | يد تحكم |
|-------|-------------|---------|
| حركة / عدوّ | WASD / Shift | العصا اليسرى / ضغطها |
| كاميرا | الماوس | العصا اليمنى |
| تفادي (i-frames) | Space | B |
| ضربة خفيفة | زر الفأرة الأيسر | RB |
| ضربة ثقيلة | Shift + زر أيسر | RT |
| صد | زر الفأرة الأيمن | LB |
| قفل على الهدف | Q (والتبديل بحركة النظرة) | ضغط العصا اليمنى |
| تفاعل (الجلوس عند موقع الراحة) | E | A |
| استدعاء/ترجّل الحصان | R | Select |

## الموازنة

كل الأرقام (صحة، ضرر، ستامينا، توقيتات الهجمات) في `Assets/_Game/Data/*.asset` —
عدّلها من الـ Inspector وجرب فوراً بدون لمس الكود. القيم الافتراضية مثبتة
باختبارات في `Assets/_Game/Tests/EditMode/DataDefaultsTests.cs`.

## بنية الكود

```
Assets/_Game/Scripts/
  Combat/   # Stamina, Health, Poise, Hitbox/Hurtbox — مشتركة بين اللاعب والأعداء
  Player/   # PlayerBrain (آلة الحالات)، الحركة، الكاميرا، الـ lock-on
  Enemies/  # EnemyBrain (نمط السولز: إعلان مسبق + نافذة عقاب)
  Core/     # GameBootstrap (بناء الساحة)، GameLoop (الموت والإعادة)
  UI/       # أشرطة الموارد، شاشة YOU DIED
  Editor/   # قائمة Tools/SoulsGame
LocalTests/ # تشغيل الاختبارات خارج Unity (للبيئات بلا محرر)
docs/       # المواصفات، الخطط، قائمة فحص الإحساس (playtest-checklist.md)
```

بعد اللعب، املأ `docs/playtest-checklist.md` — قراراته تحدد تعديلات الموازنة
قبل الانتقال للمرحلة 2 (مواقع الراحة، الأرواح، البوس).
