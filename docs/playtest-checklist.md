# قائمة فحص إحساس اللعب — المرحلة 1 (جوهر القتال)

الاختبارات الآلية تثبت الأرقام والمنطق؛ هذه القائمة تفحص ما لا تقيسه:
**هل القتال ممتع؟** تُملأ يدوياً بعد كل جلسة لعب في Unity Editor.

> تعديل الموازنة لا يحتاج كود: عدّل ملفات `Assets/_Game/Data/*.asset`
> (الضرر، الستامينا، المدد الزمنية للهجمات...) وجرب فوراً.

## التفادي (Dodge)
- [ ] **التوقيت واضح:** تستطيع تفادي ضربة العدو باستمرار بعد تعلم توقيته (i-frames من 0.1 إلى 0.4 ثانية).
- [ ] **مُرضٍ:** التدحرج عبر ضربة في اللحظة الأخيرة يعطي شعور إنجاز.
- *إن كان صعباً جداً:* وسّع نافذة الحصانة في `PlayerBrain.DodgeIFrameEnd`.

## الضربات
- [ ] **لها وزن:** الضربة الثقيلة تحس ببطئها وقوتها، والخفيفة بسرعتها.
- [ ] **الالتزام محسوس:** بدأت ضربة في وقت خاطئ → تدفع ثمنها (ما تقدر تلغيها فوراً).
- [ ] **الكومبو سلس:** ثلاث ضربات خفيفة تتسلسل طبيعياً عند الضغط المتتابع (الـ input buffer يلتقط الضغطة المبكرة).

## العدو
- [ ] **هجماته مقروءة:** وضعية التحضير (0.6 ثانية) كافية لرؤية الضربة قادمة والرد عليها.
- [ ] **نافذة العقاب عادلة:** بعد ضربته (1.2 ثانية استراحة) عندك وقت لضربة أو اثنتين.
- [ ] **كسر توازنه مجزٍ:** ضرباتك الثقيلة المتتالية تكسر توازنه وتفتح نافذة عقاب إضافية.

## الستامينا
- [ ] **القرار محسوس:** تحس أنك تدير مورداً — الهجوم المتهور يتركك بلا ستامينا أمام رده.
- [ ] **الوميض واضح:** محاولة فعل بلا ستامينا تومض الشريط ولا تنفذ شيئاً.
- [ ] **الصد متوازن:** الصد يحمي لكن استنزافه يعاقب (كسر الحرس عند النفاد).

## الكاميرا والقفل
- [ ] **القفل يلتقط الهدف الصحيح** (الأقرب في مجال الرؤية، Q أو ضغط العصا اليمنى).
- [ ] **التبديل يعمل:** حركة النظرة يميناً/يساراً أثناء القفل تبدّل الأهداف (مع أكثر من عدو — أضف نسخاً من WeaponData/الكود).
- [ ] **الفك التلقائي:** موت الهدف أو الابتعاد >20م يفك القفل.
- [ ] **الـ strafe:** أثناء القفل تتحرك جانبياً وأنت تواجه العدو.

## حلقة الموت
- [ ] شاشة YOU DIED تظهر عند الموت، وبعد ثانيتين تعود لنقطة البداية بصحة كاملة.
- [ ] العدو يعود لموقعه ودوريته بصحة كاملة.

## الحكم النهائي
- [ ] **سؤال المرحلة:** هل قتال عدو واحد في ساحة فارغة ممتع لعشر محاولات متتالية؟
  - نعم → المرحلة 2 (مواقع الراحة والأرواح والبوس).
  - لا → دوّن ما يضايقك بالضبط وعدّل الموازنة/المدد قبل أي محتوى جديد.
