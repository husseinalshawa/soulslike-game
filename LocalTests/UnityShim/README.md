# UnityShim

طبقة محاكاة رقيقة لأنواع UnityEngine التي تستخدمها سكربتات اللعبة، حتى تُترجم
وتُختبر محلياً بدون محرر Unity. **لا تُستخدم داخل Unity إطلاقاً** — هذا المجلد
خارج `Assets/` فمحرر Unity يتجاهله، وداخل Unity تُستخدم الأنواع الحقيقية.

قاعدة: نضيف هنا فقط ما تحتاجه السكربتات فعلياً، بأبسط سلوك صحيح.
